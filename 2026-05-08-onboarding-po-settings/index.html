Senior Manager — Executive handles all three stages, on POs of any amount. Simple and safe — every PO has a clear path through.

When you outgrow this →
  • Add more approvers per stage — anyone with that role can action a PO; only one needs to.
  • Split by amount — e.g. PMs handle POs under $5k, Senior Manager above. The system picks the matching approver automatically.
  • Combine — multiple approvers can each have their own amount band on the same stage.
