Cost Centre Settings

Control how cost centres are used across projects.

Require cost centres to create a new project ON BY DEFAULT

Every new project must have at least one cost centre before it can be created or activated. Projects imported in bulk without a cost centre are locked until one is assigned, so workers and timesheet approvers can never book costs to a project with no cost centre.

Also lock existing projects that have no cost centre

When turned on, the rule is applied retroactively — any current project missing a cost centre is locked until one is assigned. Off by default so existing work isn't disrupted.

Behaviour when ON: projects created via the claim schedule + budget flow, or as a one-off with a cost centre entered on the setup screen, are created already unlocked. Only bulk-imported projects without a cost centre arrive locked. Turning this OFF restores the current behaviour (cost centre optional, no locking).
