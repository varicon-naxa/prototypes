What's new in this mock-up

  • Default workflow = send to supplier. Approving a PO now emails it to the supplier automatically (the Approve button becomes Approve & Send). No separate manual Send Email step.
  • Supplier email pulled from the accounting system. The recipient is auto-filled from the connected MYOB / Xero / QuickBooks supplier record (badge shows the source) — today the To field is blank and typed in by hand each time.
  • Approve button is a split control. Default Approve & Send, with a dropdown for Approve only (don't send to supplier) and Save as draft — so the auto-send default is easy to override per PO.
  • Still reviewable. Approver can see/edit the recipient and message before it goes; falls back to the Varicon supplier record if the accounting system has no email.
  • Set once. Org-level setting (Settings → Purchase Order) turns the auto-send default on and points the email source at the accounting system.
  • Why: Gulf Civil — "if the POs don't go out, things don't get ordered in time." Removes a manual step that causes missed/late orders.
