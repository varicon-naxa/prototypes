What this prototype is for

VAR-21153 needs three screens drawn before Tech Refinement: the supervisor's who has signed view, the assign flow, and the offline sign-on screen. This prototype draws those three. It also includes the subcontractor's link page and the QR for a single record, because both add signatures to the same record.

The core idea it has to make obvious: one SWMS, one record, many signatures, whichever way each person signed.

Decisions assumed here

  • Offline sign-on is a supervisor app flow (Alec, 2026-10-07). The supervisor's phone holds the record and collects signatures while offline. VAR-21333 and VAR-21337 assumed different answers; this settles it for the prototype. The deciding fact: F & J Bitumen's sites have no reception at all, so only one device needs to work offline.
  • Each signer reads before signing. On the handed-over phone, the worker sees the key hazards and ticks "I've read and understood" before the pad unlocks. Without this, passing a phone around is the same as today's practice with extra steps.
  • Signature identity: name, role or organisation, route (own phone / supervisor's phone / link / QR), device, and a UTC timestamp. The web shows local time with UTC beneath.
  • Two signatures in the same second are both kept (Jack O'Brien and Liam Walsh, 06:51:12). Shown so the concurrency requirement is visible.

Still open — not decided by this prototype

  • Do answers lock at the first signature? The web view shows them locked (VAR-20749, field locking after signature). If they can still change, every earlier signature is on answers that moved.
  • Does an external signature carry the same weight as a crew signature, or a separate trust level? The record marks the route but treats them the same.
  • Worker's own phone screen (assign route, online) isn't drawn. Assumption: it's the existing form screen with a Sign button and the same read-and-acknowledge step.
  • Unlisted worker on the offline phone. "Add someone not on the list" is shown; whether it needs supervisor confirmation is open.
